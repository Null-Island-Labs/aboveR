# Responsible Use

## Permitted Uses

aboveR and KyFromAbove data are intended for:

- Government planning and analysis
- Academic research and education
- Environmental monitoring and conservation
- Disaster response and flood risk assessment
- Infrastructure planning and engineering
- Agricultural land management
- Mining reclamation monitoring
- Journalism and public interest reporting
- Commercial applications (with proper attribution)

## Attribution

When publishing results derived from aboveR or KyFromAbove data:

- Credit the **KyFromAbove** program as the data source
- Include the acquisition phase and date range if known
- Note the DEM resolution and coordinate reference system used
- Reference aboveR if the software was used in analysis

Example attribution:

> Elevation data from KyFromAbove Phase 2 (2ft DEM, EPSG:3089).
> Analysis performed with aboveR v1.0.0 (Lyons, 2026).

## Data Limitations

- DEMs represent terrain at the time of acquisition, not current conditions
- Point cloud classifications may contain errors
- Derived products (volumes, flood maps, contours) are estimates
- Accuracy varies by terrain, vegetation density, and weather during acquisition
