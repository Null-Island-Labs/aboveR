# Support

## Bug Reports

Open an [issue](https://github.com/chrislyonsKY/aboveR/issues) with:

- **aboveR version:** `packageVersion("aboveR")`
- **R version:** `R.version.string`
- **OS:** `Sys.info()["sysname"]`
- **Minimal code** to reproduce the problem
- **Full error message** including traceback

Use the [bug report template](https://github.com/chrislyonsKY/aboveR/issues/new?template=bug_report.yml)
for a guided form.

## Feature Requests

Open an [issue](https://github.com/chrislyonsKY/aboveR/issues) describing:

- The use case or problem you're trying to solve
- How you'd expect the API to work (function name, parameters, return value)
- Any relevant KyFromAbove data products or workflows
- Whether the feature exists in AbovePy (Python sibling package)

Use the [feature request template](https://github.com/chrislyonsKY/aboveR/issues/new?template=feature_request.yml).

## Security Vulnerabilities

**Do not** open a public issue for security concerns. Email **chris.lyons@ky.gov**
directly. See [SECURITY.md](SECURITY.md) for the full policy.

## KyFromAbove Data Issues

For issues with the underlying KyFromAbove data (missing tiles, incorrect
elevations, acquisition coverage), contact the KyFromAbove program directly:

- Email: kyfromabove@ky.gov
- Website: [kyfromabove.ky.gov](https://kyfromabove.ky.gov)

## General Questions

For general R spatial questions not specific to aboveR, consider:

- [R-sig-Geo mailing list](https://stat.ethz.ch/mailman/listinfo/r-sig-geo)
- [GIS Stack Exchange](https://gis.stackexchange.com/) (tag: `r`)
- [Stack Overflow](https://stackoverflow.com/) (tag: `r`, `terra`, `sf`)
